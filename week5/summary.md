周一：Deep Agent 基础框架搭建
  ├── 注册 Tavily 搜索 API（专为 AI Agent 设计的搜索引擎）
  ├── 创建网络搜索工具
  ├── 创建 Python 计算器工具
  ├── 接入本地金融信号数据
  └── 构建三工具协同的 Deep Agent

周二：MCP 风格工具封装 + 统一工具调用接口
  ├── 理解 MCP（Model Context Protocol）核心思想
  ├── 定义 ToolDefinition（工具元数据 + 参数Schema）
  ├── 实现 ToolRegistry（工具注册中心）
  └── 将三个工具按 MCP 规范统一封装

周三：调研计划模板 + 四阶段分析流程
  ├── 设计 ResearchPlan 类（计划→执行→检查→输出）
  ├── 创建“茅台vs五粮液”标准对比模板
  ├── 实现 LLM 动态规划（根据用户问题自动生成计划）
  └── 测试四阶段自动执行（调研→数据→分析→报告）

周四：反思机制 + 自动纠错
  ├── 创建搜索质量检查器（结果是否包含具体数据）
  ├── 创建计算合理性检查器
  ├── 实现数据完整性检查
  ├── 实现自动重试（最多3次，每次改进搜索词）
  └── 对比有无反思机制的 Agent 表现

周五：实战——茅台 vs 五粮液完整对比分析
  ├── 执行完整六阶段分析流程
  ├── 输出专业级 Markdown 分析报告
  ├── 保存报告到 data/ 目录
  └── 第五周收尾总结
