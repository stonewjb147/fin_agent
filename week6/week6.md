📚 第一阶段：思维奠基（约1-2天）

在写任何代码之前，首先需要理解 LangGraph 的核心理念。它是对传统线性工作流（如 LangChain 的 Chain）的升级，专为处理包含循环、分支和状态回溯的复杂任务而设计。

· 核心思想：将智能体工作流建模为一张“图”（Graph）。图由三部分组成:
  1. State (状态)：节点间共享的数据“黑板”。
  2. Nodes (节点)：执行具体任务的“工位”函数。
  3. Edges (边)：连接节点的“传送带”，定义执行路径，包括普通边和带条件判断的条件边。
· 环境准备：创建 Python 虚拟环境并安装 LangGraph（版本建议 ≥ 1.0.0）。
  ```bash
  pip install langgraph
  ```

🛠️ 第二阶段：核心开发（从Hello World到基础Agent）

这个阶段的目标是跑通第一个有状态的图，并让 Agent “活”起来。LangGraph 官方提供了丰富的教程，建议按此顺序练习：

1. 定义状态 (State)
状态是一个 TypedDict，定义图中流转的数据结构。一个典型的 MessagesState 包含对话历史。

```python
from typing import Annotated, List, Literal
from typing_extensions import TypedDict
from langchain_core.messages import BaseMessage
import operator

class AgentState(TypedDict):
    messages: Annotated[List[BaseMessage], operator.add]  # 对话历史（追加模式）
    current_step: Literal["search", "generate", "end"]    # 当前步骤
    user_query: str                                       # 用户原始问题
```

operator.add 作为 Reducer，定义了多个节点对同一字段的更新策略（追加）。

2. 构建节点 (Nodes)
节点是 Python 函数，接收并返回 State。每个节点负责一个任务，如调用大模型、执行工具、生成报告等。

3. 设计边 (Edges)
边定义节点执行顺序。

· 普通边 (Normal Edge)：顺序执行，如 graph.add_edge("node_a", "node_b")。
· 条件边 (Conditional Edge)：根据 State 动态选择下一节点，是实现“分支”和“循环”的关键。

4. 编译与测试
使用 StateGraph 编排节点和边，调用 .compile() 编译成可执行图。然后通过 graph.invoke() 传入初始状态来运行。

因子：
作为量化分析师，我们首先需要明确“因子”的本质。在量化投资中，因子就是能够解释资产收益差异、帮助进行资产定价的核心特征。它把模棱两可的“盘感”和市场经验，转化为了清晰、可回测的数学规则。

从当下的视角来看，主流的金融因子主要可以分为三大阵营：基本面因子（基于公司财务与内在价值）、量价因子（基于市场交易数据）以及另类数据因子（基于非结构化数据）。

以下为你梳理的核心量化因子指引：

一、 基本面因子 (Fundamental Factors)
基本面因子主要反映公司的内在价值和财务状况，适合用于中长期的投资逻辑构建。

*   价值因子 (Value)
    *   含义：核心逻辑是寻找“便宜货”，即价格低于其内在价值的股票。
    *   常用指标：市盈率（PE）、市净率（PB）、市销率（PS）、股息率等。
    *   使用场景：适用于均值回归策略。当市场对某些板块过度悲观导致估值极低时，价值因子能有效捕捉估值修复的收益。
*   质量因子 (Quality)
    *   含义：寻找财务健康、盈利能力强劲且稳定的“好学生”。
    *   常用指标：净资产收益率（ROE）、毛利率、资产负债率、经营现金流/净利润。
    *   使用场景：在宏观经济下行或市场震荡期，质量因子具有极强的防御属性，能有效规避财务爆雷风险。
*   成长因子 (Growth)
    *   含义：寻找具有高增长潜力的“潜力股”。
    *   常用指标：营收增速、净利润复合增长率（CAGR）、研发投入占比。
    *   使用场景：在信用扩张、流动性充裕的牛市或结构性行情中，成长因子往往能带来极高的超额收益。

二、 量价因子 (Price & Volume Factors)
量价因子直接反映市场参与者的行为模式，对市场变化反应极其敏感，是A股量化策略中应用最广的类别。

*   动量因子 (Momentum)
    *   含义：核心逻辑是“强者恒强”，追涨杀跌。
    *   常用指标：过去1个月/3个月/6个月的收益率、相对强弱指数（RSI）。
    *   使用场景：在单边趋势确立的市场中表现极佳，适合右侧交易和趋势跟踪策略。
*   反转因子 (Reversal)
    *   含义：核心逻辑是“物极必反”，跌多了会涨，涨多了会跌。
    *   常用指标：短期涨跌幅、超买超卖指标、偏离均线幅度。
    *   使用场景：在A股的震荡市中，反转因子往往比动量因子更有效，常用于短期抄底或大涨止盈。
*   波动率因子 (Volatility)
    *   含义：存在“低波动异象”，即走势平稳、不怎么大涨大跌的股票，长期风险调整后收益反而更高。
    *   常用指标：历史波动率、Beta系数、最大回撤。
    *   使用场景：用于构建低波组合，控制投资组合的下行风险，适合风险厌恶型资金。
*   流动性因子 (Liquidity)
    *   含义：衡量股票买卖的活跃程度，流动性好的股票不容易被“套死”。
    *   常用指标：日均成交额、换手率、Amihud指标。
    *   使用场景：作为基础筛选条件，规避流动性枯竭的个股；或者利用“缩量筑底”等特征寻找底部反转机会。

️ 三、 另类数据因子 (Alternative Data Factors)
随着传统因子的拥挤度上升，另类数据因子正成为机构挖掘超额收益（Alpha）的新蓝海。

*   情绪因子 (Sentiment)
    *   含义：通过非结构化数据捕捉市场参与者的贪婪与恐慌。
    *   常用指标：新闻文本情绪得分、社交媒体讨论热度、期权PCR（看跌/看涨比率）。
    *   使用场景：作为择时信号。当市场情绪极度恐慌时买入，极度狂热时减仓。
*   供应链与产业因子 (Supply Chain & Industry)
    *   含义：利用上下游产业链数据或高频产业数据来预判公司业绩。
    *   常用指标：供应商/客户动量、卫星图像数据（如停车场车流量）、高频物流数据。
    *   使用场景：具有极强的前瞻性，能在官方财报发布前提前捕捉到公司基本面的边际变化。

总结与实战建议

在实际的量化模型中，我们极少依赖单一因子，而是采用多因子组合（Multifactor）。例如，构建一个“高质量+低估值+强动量”的策略。

需要特别注意的是因子轮动（Factor Rotation）。没有任何一个因子是永远有效的，因子的表现具有明显的周期性。比如在经济上行期，成长因子可能占优；而在震荡市中，反转因子可能表现更好。因此，优秀的量化分析师不仅要懂得挖掘因子，更要懂得结合宏观经济周期和市场情绪，动态调整不同因子的权重。

LangGraph 是什么？

LangGraph 是由 LangChain Inc. 开发的一个低级别编排框架，专门用于构建、管理和部署长期运行、有状态的 AI 智能体（Agent）。

简单来说，它的核心思想是：用"图"（Graph）的方式来编排 AI 工作流。

- 节点（Node）：每个节点代表一个功能模块，比如"抓取数据"、"清洗数据"、"生成信号"
- 边（Edge）：定义节点之间的控制流和数据传递，支持条件分支和循环
- 状态（State）：一个中央状态对象在整个图中流转，每个节点可以读取和更新它

它解决什么问题？

传统的 AI 应用开发（比如用 LangChain 的 Chain 模式）是线性的，一旦涉及以下场景就很痛苦：

- 需要循环：比如"抓取数据 → 质量检查 → 不合格则重新抓取"
- 需要条件分支：比如"根据市场类型路由到不同的数据源"
- 需要状态持久化：比如"任务中断后能从断点恢复"
- 需要人工介入：比如"信号异常时暂停，等人工确认后再继续"

LangGraph 把这些都原生支持了。
