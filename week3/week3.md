MCP服务调用

用户: "帮我查一下关于茅台的新闻，要5条"
                    ↓
┌─────────────────────────────────────────────────────────────────┐
│ 大模型（DeepSeek）                                              │
│  1. 理解意图 → 选择工具 get_finance_news                        │
│  2. 提取参数:                                                  │
│     - keyword = "茅台"  ← 从"关于茅台"提取                      │
│     - limit = 5        ← 从"要5条"提取                         │
│     - category = "caijing" ← 使用默认值                        │
│  3. 生成调用请求 → {"name": "...", "arguments": {...}}          │
└─────────────────────────────────────────────────────────────────┘
                    ↓ (通过MCP协议发送)
┌─────────────────────────────────────────────────────────────────┐
│ MCP服务器                                                       │
│  1. 收到请求: {"name": "get_finance_news", "arguments": ...}    │
│  2. 从 arguments 提取参数:                                      │
│     keyword = arguments.get("keyword")  → "茅台"               │
│     category = arguments.get("category") → "caijing"           │
│     limit = arguments.get("limit")      → 5                    │
│  3. 调用函数: get_finance_news(keyword="茅台", limit=5)         │
└─────────────────────────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────────────────────────┐
│ 业务函数 get_finance_news                                       │
│  接收: keyword="茅台", category="caijing", limit=5              │
│  执行: 请求聚合数据API，过滤包含"茅台"的新闻                     │
│  返回: 5条新闻列表                                              │
└─────────────────────────────────────────────────────────────────┘
                    ↓
大模型收到结果 → 组织语言 → 回复用户
